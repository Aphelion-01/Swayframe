你现在需要把当前已经可以运行的 Swayframe Web Editor 改造成真正可安装、可长期使用的桌面端创作软件。

本次任务的核心原则只有一句：

======================================================================
Desktopize the existing editor. Do NOT rewrite the editor.
======================================================================

当前项目中已经存在的：

React
TypeScript
Canvas Editor
Timeline
Graph Editor
Motion Curve
Layer System
Property System
Keyframe System
Command System
Undo / Redo
Project Model
Renderer
Inspector
Effects
2D / 2.5D 编辑功能

都必须尽可能保留和复用。

禁止因为“改成桌面版”而：

- 使用 Swift 重写 macOS 版本
- 使用 WinUI / WPF 重写 Windows 版本
- 使用 C++ 重写现有 Editor
- 重建一套新的 Scene Model
- 重建一套新的 Timeline
- 复制一份 Desktop 专用业务逻辑
- 将现有 Web 版丢弃后另起炉灶

当前 Editor 就是未来桌面软件的编辑核心。

桌面化只负责增加：

======================================================================
五、建立统一 Desktop API
======================================================================

建立清晰接口：

interface DesktopAPI {

  project: {
    newProject(): Promise<void>
    open(): Promise<OpenProjectResult | null>
    save(projectData): Promise<SaveResult>
    saveAs(projectData): Promise<SaveResult>
  }

  dialog: {
    openFile(options): Promise<string[]>
    openFolder(options): Promise<string | null>
    saveFile(options): Promise<string | null>
  }

  assets: {
    importFiles(): Promise<ImportedAsset[]>
    readMetadata(path): Promise<AssetMetadata>
    exists(path): Promise<boolean>
  }

  recentProjects: {
    list(): Promise<RecentProject[]>
    add(project): Promise<void>
    remove(path): Promise<void>
    clear(): Promise<void>
  }

  window: {
    setTitle(title): Promise<void>
    setDocumentEdited(edited): Promise<void>
  }

  platform: {
    getInfo(): Promise<PlatformInfo>
  }
}

所有 Editor 代码通过：

DesktopService

调用。

禁止 React Component 直接知道 Electron IPC Channel 名称。

目标：

未来如果 Electron 被替换，

Editor Core 不需要重写。
