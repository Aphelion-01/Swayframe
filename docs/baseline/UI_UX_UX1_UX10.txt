你现在需要对当前 Motion Design Editor 进行一次系统性的 UI / UX 重构。

本轮任务的核心不是新增动画功能，也不是简单“美化界面”。

核心目标是：

======================================================================
重新建立一套专业、稳定、低学习成本的动画编辑器交互范式。
======================================================================

当前软件已经具有：

Canvas
Layer
Inspector
Timeline
Keyframe
Curve Editor
Composition
Shape
Text
以及其他基础动画能力。

但是目前 UI 存在明显问题：

1. 功能按钮大量平铺在界面上；
2. 顶部工具栏承担过多职责；
3. Timeline 控件过于拥挤；
4. 不同功能之间缺乏清晰视觉层级；
5. 高频操作和低频操作混在一起；
6. Canvas 缺乏专业设计软件应有的直接操作体验；
7. 很多操作仍然具有“网页表单”感，而不是“桌面创作软件”感；
8. 面板尺寸、信息密度、控件层级不够统一；
9. 用户难以快速形成肌肉记忆；
10. 界面整体缺乏明确的 Workspace 概念。

本轮不要追求独特设计语言。

优先参考成熟专业软件长期验证过的交互方式：

Adobe After Effects：
Timeline、Layer、Keyframe、Graph Editor、Composition 工作逻辑。

Figma：
Canvas、Selection、Transform、Zoom/Pan、Direct Manipulation、
Inspector、工具栏、快捷键等交互方式。

可以参考它们的“交互范式和信息架构”，
但禁止直接复制：

品牌视觉
图标资源
专有图形
Logo
代码
商业 UI Assets。

当前目标不是创新 UI。

当前目标是：

======================================================================
先把编辑器做得“像一个真正成熟的专业创作软件”。
======================================================================
