# 第三阶段：为 Skill 写入以下设计原则

`professional-creative-editor-ui` 至少必须包含以下规则。

## 1. Professional Tool First

这个产品首先是一个专业创作工具，而不是网站。

不要把界面设计成：

```text
Dashboard
Card Grid
Landing Page
SaaS App
AI Chat Website
```

避免：

- 大卡片堆叠
- 到处都是圆角容器
- 大面积无意义留白
- 巨型标题
- 巨型按钮
- 大面积渐变
- 玻璃拟态泛滥
- 每个功能一个 Card
- 每个区域都有 Border
- 所有内容都浮起来
- “AI Website”视觉风格

---

# 2. Desktop Creative Software Mental Model

整个软件应该建立稳定的桌面创作软件布局模型：

```text
┌─────────────────────────────────────────────┐
│ Menu / Global Toolbar                      │
├──────────┬──────────────────────┬───────────┤
│          │                      │           │
│ Assets / │    Main Canvas /     │ Inspector │
│ Tools    │    Composition       │ Properties│
│          │                      │           │
├──────────┴──────────────────────┴───────────┤
│ Timeline / Node Graph / Workflow           │
└─────────────────────────────────────────────┘
```

具体结构可以根据现有项目进行调整，但必须保持稳定的：

**Left Tool Area**

**Center Workspace**

**Right Inspector**

**Bottom Timeline / Node / Workflow Area**

不要让核心模块随意漂浮。

- context menu
- toolbar

- command palette

# 5. Density

这是生产力工具。

默认使用：

```text
medium-high information density
```

不要按照消费者 App 设计。

避免：

```text
48px / 56px 巨大按钮
24px 巨大内边距
巨大卡片
大量空白
```

优先采用：

```text
compact controls
compact toolbar
compact list
compact inspector
tight but breathable spacing
```

但不要拥挤。

---

# 6. Spacing System

建立统一 spacing token。

例如：

```text
2
4
6
8
12
16
24
32
```

不要出现大量：

```text
13px
17px
19px
23px
```

这种随机 spacing。

扫描项目中的：

```text
padding
margin
gap
height
width
```

逐步统一。

---

# 7. Border Radius

专业创作软件应采用克制圆角。

避免：

```text
rounded-xl
rounded-2xl
rounded-3xl
```

到处使用。

建议：

```text
small controls:
2–4px

panels:
0–6px

floating popover:
4–8px
```

只有真正需要强调的组件才能使用更大的 radius。

---

# 8. Color System

建立真正的 Design Token。

至少包括：

```text
background-primary
background-secondary
background-tertiary

surface-hover
surface-active
surface-selected

border-subtle
border-strong

text-primary
text-secondary
text-muted

accent-primary
accent-hover

danger
warning
success
```

禁止在几十个文件里重复硬编码随机颜色。

---

# 9. Dark UI

如果当前项目是暗色 UI，则整体方向保持：

```text
professional neutral dark
```

不要：

- pure black everywhere
- excessive blue
- cyberpunk neon
- gaming UI
- glassmorphism everywhere

应该像真正工作几个小时不会疲劳的创作软件。

强调色只负责：

```text
selection
active tools
important state
AI action
```

不要让所有按钮都是强调色。

---

# 10. Typography

建立清晰文字体系。

至少包括：

```text

Section label

```

专业软件应避免：

```text

营销式 Typography
页面式 H1/H2/H3
```

Panel Header 应紧凑。

# 11. Icons

检查：

- icon size
- stroke width
- optical alignment
- icon/button padding
- selected state
- hover state

不要：

- emoji 作为正式工具图标
- 多套不同视觉风格 icon
- 一个地方 14px 一个地方 28px
- icon 与文字基线错位

如果项目已经采用图标库，则优先继续使用现有库。

不要因为 UI 优化随意增加大量依赖。

# 20. Motion

UI 动画必须克制。


主要用于：

- panel
- hover
- menu
- selection
- inspector
- tab
- modal
- node interaction

不要：

- exaggerated bounce
- unnecessary spring
- cinematic animation
- slow transitions

专业工具第一目标是响应速度。
