特别注意：

Capability ID

不等于：

Tool Name

也不等于：

Command ID。

三者允许不同，
但必须具有明确、可验证的映射。

例如：

Capability:

shape.rectangle

Tool:

createShape

Command:

layer.create

这是可能合理的设计。

但具体映射必须来自真实 Registry。

不能由 LLM 自行推测。

如果 shape.rectangle 是合法的语义能力，
但没有注册到正式能力目录：

修复真实注册链路。

如果它实际上不是合法能力 ID：

修复 Planner / Skill 暴露错误标识的原因。

禁止：

直接将所有未知字符串加入白名单。

不得无限重试。

根据正式 Schema 修复。

停止无效尝试。

不要：

所有错误统一交给 LLM 再试一次。

不要：

通过不断增加 Recovery Budget
掩盖真实契约不一致。
