TRANSFORM ORIENTATION + PIVOT SYSTEM
######################################################################

======================================================================
1. 设计目标
======================================================================

当前 Swayframe 的 Transform 行为过于固定。

用户进行：

Move
Scale
Rotate

需要能够明确控制：

A.
变换轴使用什么坐标系。

B.
变换围绕哪个 Pivot 进行。

这两个概念必须严格区分。

不要混成一个 Dropdown。


======================================================================
2. 两个独立概念
======================================================================

建立：

Transform Orientation

和：

Transform Pivot

两个独立系统。


Transform Orientation：

Global
Local
Parent
View

以后可以扩展：

Normal
Custom Orientation


Transform Pivot：

Anchor

Object Center

Bounding Box Center

Custom Pivot


不要因为第一版功能较少，
把它们写死成几个 if。


======================================================================
3. Transform Orientation 定义
======================================================================

GLOBAL

使用 Composition / World 坐标。

例如：

X：

始终表示世界水平轴。


LOCAL

使用对象自己的旋转坐标。

例如：

一个对象 Rotation = 45°。

Local X：

沿对象自身横向。


PARENT

如果 Layer 有 Parent：

使用 Parent Transform 坐标。

如果没有 Parent：

fallback：

Global。


VIEW

使用当前 Viewer / Camera View 坐标。

2D 环境中：

通常等价于 Screen Space。

2.5D / Camera 模式：

使用 Camera View Orientation。


======================================================================
4. Transform Pivot 定义
======================================================================

ANCHOR

使用 Layer 自己现有：

Anchor Point。

这是传统动画软件行为。


OBJECT CENTER

使用对象本身几何中心。

注意：

它和 Anchor Point 不一定相同。


BOUNDING BOX CENTER

使用当前对象视觉 Bounding Box 中心。

例如：

Shape
Text
Image

都应使用实际 Bounds。


SELECTION CENTER

多选对象时：

计算整个 Selection Bounding Box：

minX
minY
maxX
maxY

Pivot：

center(selection bounds)


INDIVIDUAL ORIGINS

多选时：

每个对象围绕自己的 Pivot 独立 Transform。

例如：

同时 Scale 3 个对象。

Selection Center：

三者围绕共同中心放大。

Individual Origins：

三者分别原地放大。


CUSTOM PIVOT

允许用户在 Canvas 设置一个临时 Transform Pivot。

第一版可以：

不写入 Layer Anchor。

它属于：

Transform Interaction State

而不是：

Layer Property。

以后可以扩展成：

Transform Cursor。


======================================================================
5. 非常重要：
Pivot ≠ Anchor
======================================================================

不要为了实现：

Object Center

直接修改：

Layer.anchorPoint。

例如：

用户临时选择：

Pivot = Object Center

进行一次 Scale。

操作完成后：

Layer Anchor

仍然保持原值。

Transform Pivot 是：

“本次 Transform 如何计算”

Anchor 是：

“Layer 持久属性”。

两者必须分离。


======================================================================
6. 底层状态
======================================================================

建议建立：

interface TransformInteractionSettings {
    orientation: TransformOrientation;
    pivotMode: TransformPivotMode;
    customPivot?: Vec2 | Vec3;
}

例如：

type TransformOrientation =
    | "global"
    | "local"
    | "parent"
    | "view";

type TransformPivotMode =
    | "anchor"
    | "object-center"
    | "bounds-center"
    | "selection-center"
    | "individual-origins"
    | "custom";

这些设置优先属于：

Editor / Workspace State。

不要默认写进 Project Scene。

用户切换工程：

可以沿用自己的编辑习惯。


======================================================================
7. Transform Operation Context
======================================================================

不要让：

Move Tool
Scale Tool
Rotate Tool

分别自己计算 Pivot。

建立统一：

TransformContext。

例如：

interface TransformContext {

    selectedLayerIds: LayerId[];

    orientation: TransformOrientation;

    pivotMode: TransformPivotMode;

    pivot: Vec2 | Vec3;

    basis: TransformBasis;

    initialTransforms: Map<
        LayerId,
        TransformSnapshot
    >;
}

所有：

Move
Scale
Rotate

共享。


======================================================================
8. Pivot Resolver
======================================================================

建立：

resolveTransformPivot(...)

例如：

resolveTransformPivot(
    selection,
    pivotMode,
    scene,
    time
)

→ Vec2 / Vec3


ANCHOR：

单选：

当前 Layer Anchor world position。


OBJECT CENTER：

Layer geometry center。


BOUNDS CENTER：

Layer world bounding box center。


SELECTION CENTER：

所有选中 Layer Bounds union center。


INDIVIDUAL ORIGINS：

不返回一个公共中心。

返回：

Map<LayerId, Pivot>


CUSTOM：

使用当前 customPivot。


======================================================================
9. Orientation Resolver
======================================================================

建立：

resolveTransformBasis(...)

根据：

orientation

返回：

basis vectors / matrix。

不要在 UI 里写坐标计算。


GLOBAL：

world axes


LOCAL：

layer local transform basis


PARENT：

parent basis


VIEW：

camera / screen basis


======================================================================
10. Scale 数学
======================================================================

Scale 必须真正围绕 Pivot 进行。

对于单个对象：

原 world position：

P

Pivot：

C

Scale factor：

S

新的位置：

P' = C + S * (P - C)

然后：

Layer 自身 Scale

也同时改变。


对于 2D：

分别：

sx
sy


对于 Uniform Scale：

sx = sy。


关键：

改变 Scale 时，

如果 Pivot 不等于 Anchor，

Position 通常也必须补偿。

不能只改：

layer.scale

否则视觉中心不会保持不动。


======================================================================
11. Rotate 数学
======================================================================

Rotation 同理。

原位置：

P

Pivot：

C

旋转矩阵：

R

新的 Position：

P' = C + R(P - C)

然后：

Layer Rotation

增加：

Δθ。


多选 Selection Center：

所有 Layer 围绕公共 C 旋转。


Individual Origins：

每个 Layer：

只改变自己 Rotation

位置不绕公共中心移动。


======================================================================
12. Move + Orientation
======================================================================

Move 一般不依赖 Pivot，

但依赖：

Orientation。

例如：

Local X Move：

沿对象自身 X 方向。

Global X Move：

沿 World X。

因此：

Orientation

必须覆盖：

Move
Scale
Rotate。

Pivot 主要影响：

Scale
Rotate。
