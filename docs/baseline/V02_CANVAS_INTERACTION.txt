你现在开始进行 Swayframe V0.2 的第二轮专项优化：

======================================================================
Canvas Interaction / Direct Manipulation
======================================================================

本轮唯一目标：

把 Swayframe 的 Canvas 从“能显示和编辑对象”

提升到：

“真正具有专业设计软件操作手感的直接编辑画布”。

交互体验参考：

Figma
After Effects
Illustrator

但不要照抄其 UI 视觉。

重点学习：

Selection
Direct Manipulation
Transform
Pan / Zoom
Multi-selection
Bounding Box
Anchor
Snapping
Drag Behavior
Undo Semantics

本轮不要：

重构 Timeline

增加新 Effects

开发 AI Agent

扩张 Compositing Graph

开发高级 3D

新增大量 Layer Type

除非某个问题直接阻塞 Canvas。

======================================================================
二、建立明确 Tool System
======================================================================

建立统一：

Tool System

至少支持：

Selection Tool

Rectangle Tool

Ellipse Tool

Text Tool

重点先做：

Hand

其他保持现有能力。

Tool 状态必须是统一来源。

不要：

Canvas 一个 tool state

Toolbar 又一个 tool state。

======================================================================
三、Selection Tool
======================================================================

Selection Tool 是当前最高优先级。

基础行为：

Click Object

→ Select

Click Empty Area

→ Clear Selection

Shift + Click

→ Add / Remove selection

Cmd/Ctrl + Click

根据当前交互规范：

支持层级内选择或追加选择。

行为必须统一。

选中对象后：

Canvas

Layer Panel

Inspector

Timeline

保持同步。

不要多个 Panel 自己维护 selection。

======================================================================
四、点击命中检测
======================================================================

实现稳定 Hit Testing。

用户点击对象时：

选择视觉上真正位于鼠标下方的对象。

考虑：

Layer Z order

Transform

Rotation

Scale

Nested composition

Mask

3D Layer projection（如果已有）

对于重叠对象：

默认选择最上层可见对象。

后续可通过：

Cmd/Ctrl + Click cycling

或 Context Selection

选择下层对象。

第一阶段至少保证顶层选择正确。

======================================================================
五、Marquee Selection
======================================================================

在空白 Canvas 拖动：

创建 Selection Marquee。

支持：

左上 → 右下

右下 → 左上

选择与框选区域相交 / 完全包含对象的规则要统一。

建议第一版：

只要 Bounding Box 与 Marquee 相交即可选中。

Shift + Marquee：

添加到当前 selection。

Alt/Option：

如果设计合理，可用于减选。

必须提供清晰 selection rectangle。

======================================================================
六、Multi-selection
======================================================================

选中多个对象后：

显示 Combined Bounding Box。

拖动 Combined Bounding Box：

所有对象一起移动。

Scale：

围绕共同 pivot / bounding box。

Rotate：

整体旋转。

Inspector：

如果属性不同：

显示 Mixed。

例如：

Position X:

—

而不是显示其中一个对象的值。

当前阶段至少完成：

Move

Scale

Rotate

多选。

======================================================================
七、Bounding Box
======================================================================

选中单个对象后：

显示专业 Bounding Box。

至少有：

四角 Scale Handles

四边 Scale Handles

Rotation interaction

Bounding Box 必须跟随：

Position

Scale

Rotation

实时更新。

不要：

对象旋转后 Bounding Box 仍是 axis-aligned 外框

如果当前 Transform Engine 支持 oriented bounds：

优先使用。

======================================================================
八、Scale
======================================================================

拖角点：

Uniform / proportional scaling。

Shift：

根据当前产品规则：

锁定 / 解除比例。

确定一个统一规则并保持一致。

不要不同 Shape 行为不同。

拖边：

单轴 Scale。

支持：

负 Scale

如果当前模型允许。

Scale 不允许因为：

Canvas Zoom

导致鼠标敏感度变化错误。

Transform 计算必须使用：

Canvas Space
→
World / Composition Space

正确转换。

======================================================================
九、Rotation
======================================================================

用户把鼠标移动到 Bounding Box 边角外：

显示 Rotate Cursor。

Drag：

Rotation。

围绕：

Anchor / Pivot

旋转。

支持：

Shift

Angle snapping：

15°

或者项目统一角度。

Rotation 应连续流畅。

跨越：

359°
→
0°

不能出现突然跳变。

======================================================================
十、Anchor / Pivot
======================================================================

Anchor 是 Motion Design 的核心能力。

选中对象：

显示 Anchor Point。

提供：

Anchor Tool

或者：

Alt/Option + interaction

用于移动 Anchor。

移动 Anchor 时：

默认保持对象视觉位置不变。

即：

改变 Anchor

同时补偿 Position。

这是专业动画软件应有行为。

如果当前项目已有 Anchor：

检查数学是否正确。

特别测试：

Rotation 后移动 Anchor

Scale 后移动 Anchor

Parented Layer

3D Layer

第一阶段至少保证 2D 正确。

======================================================================
十一、Move
======================================================================

Drag selected object：

Move。

拖动过程中：

实时 Preview。

Mouse Up：

Commit Command。

整个 drag：

只产生一个 Undo Step。

实现：

Drag Start

Drag Update

Drag Commit

Drag Cancel

Esc：

取消本次 Drag

恢复到 Drag Start 状态。

禁止：

mousemove 每次写入 History。

======================================================================
十二、Axis Constraint
======================================================================

移动对象时：

Shift：

锁定水平 / 垂直移动。

判断依据：

初始拖动方向。

例如：

开始偏水平

→ lock X movement

开始偏垂直

→ lock Y movement。

行为要稳定。

不要鼠标略微抖动就在 X/Y 间来回切换。

======================================================================
十三、Duplicate Drag
======================================================================

如果平台习惯允许：

Alt / Option + Drag

复制对象并移动。

行为：

Drag Start

创建 duplicate preview

Drag Commit

最终成为一次 Transaction。

Undo：

一步删除复制结果。

不要：

Duplicate

和：

Move

分别产生两个 Undo Steps。

======================================================================
十四、Pan
======================================================================

实现专业 Canvas Pan。

推荐：

→ Pan

Middle Mouse Drag

→ Pan

→ Drag Pan

松开：

返回之前 Tool。

如果正在：

Text Editing

不要错误拦截 Space。

======================================================================
十五、Zoom
======================================================================

Zoom 是本轮重点。

必须支持：

Cmd/Ctrl + Wheel

或项目统一鼠标规则。

关键要求：

======================================================================
Zoom around cursor
======================================================================

缩放中心必须是：

鼠标所在 Canvas Point。

不能每次围绕：

Composition Center。

数学上保证：

Zoom 前

鼠标下的 composition point

Zoom 后

仍尽量位于鼠标下。

这是 Figma 类工具手感的重要来源。

三十七、Interaction State Machine
======================================================================

如果当前 Canvas 事件逻辑已经复杂：

例如：

hovering

marqueeSelecting

moving

scaling

rotating

panning

editingText

editingPath

几十个 boolean

互相冲突。
