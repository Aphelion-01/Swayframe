你现在负责继续开发当前 AI-native Motion Design 项目。

在开始编码前，必须先完整阅读当前仓库、ARCHITECTURE.md、现有 README、已有数据模型、Command System、渲染相关代码和测试。优先继承现有架构，不允许为了快速实现功能而推倒重写。

本阶段的目标发生调整：

暂时不要重点开发 AI Agent、自动排版、神经网络或生成式视频能力。

当前最高优先级是：

======================================================================
把软件首先建设成一个真正能够完成大部分常规二维 Motion Design 工作的动画编辑器，
并加入一套简单但完整可用的 2.5D / 3D 合成功能。
======================================================================

可以参考 After Effects 的核心工作方式，但不要试图完整复制 AE，也不要复制其历史包袱。

最终目标不是“做出很多按钮”，而是让用户能够真正完成：

素材导入
→ 图层组织
→ 图形/文字设计
→ 属性编辑
→ 关键帧动画
→ 速度曲线调整
→ 遮罩
→ 调色与基础效果
→ 预合成
→ 简单 3D 空间动画
→ 实时预览
→ 导出

这样一个完整工作流。

所有功能必须服务于这个闭环。

一、最重要的开发原则
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 不允许只创建 UI 空壳。

任何出现在界面中的主要功能都必须实际工作。

2. 不允许为了赶功能数量破坏现有架构。

继续坚持：

UI
↓
Command System
↓
Project / Scene Model
↓
Animation / Render System

UI 不允许直接修改 Scene 数据。

未来 AI Agent 也必须能够通过同一套 Command System 使用这些功能。

3. 保持 Human-first。

当前阶段所有核心功能都必须可以由用户直接通过 GUI 操作完成。

不要假设用户需要 Prompt 才能使用软件。

4. 所有可动画属性尽可能使用统一 Property<T> 系统。

例如：

Position
Scale
Rotation
Opacity
Color
Blur Radius
Mask Feather
Effect Parameters

都应能够进入：

Property<T>
+
Keyframes
+
Interpolation

避免每种功能单独发明动画系统。

5. Renderer 与 Editor 解耦。

编辑器操作 Scene；
Animation Engine 根据时间求值；
Renderer 负责显示最终画面。

6. 所有编辑操作都必须尽量支持：

Undo
Redo

多步骤复杂操作使用 Transaction。

7. 不要在本阶段实现超出目标的大型功能。

明确禁止为了“像 AE”而开始实现：

高级粒子系统
完整 3D 建模器
骨骼绑定
复杂角色动画系统
摄像机跟踪
Rotoscoping
高级抠像
完整 Expressions 语言
第三方插件兼容层
完整 AE 文件兼容
节点式 VFX 软件
复杂物理模拟
大型 AI 模型
生成式视频模型

因此 Graph / Curve 数据模型必须独立于 UI。
