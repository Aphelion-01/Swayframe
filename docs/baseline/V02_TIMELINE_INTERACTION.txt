你现在开始进行 Swayframe V0.2 的第三轮专项优化：

======================================================================
Timeline / Keyframe Editing 专项
======================================================================

本轮唯一目标：

把当前 Timeline 从“能显示关键帧、能做基础动画”

提升为：

“真正具有专业 Motion Design 软件操作效率的动画时间轴”。

交互逻辑重点参考：

After Effects
+
现代桌面创作软件

但不要直接复制其视觉风格或代码。

本轮重点：

Layer Tree
Property Tree
Keyframe
Playhead
Timeline Navigation
Selection
Drag
Copy / Paste
Snapping
In / Out Point
Timeline Zoom
Property Filtering
Graph Editor 入口
Undo Semantics
Performance

本轮不要：

大改 Canvas
新增 Effects
增加 AI Agent
扩张 Compositing Graph
开发高级 3D
新增大量 Layer Type

除非某项直接阻塞 Timeline。
