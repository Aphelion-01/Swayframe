你现在需要专项重构 Swayframe 当前的：

Motion Curve Editor / Graph Editor

本轮目标不是增加新的曲线算法，而是：

======================================================================
彻底重新设计当前曲线编辑器的 UI 布局、信息层级和操作流程，
让它变成一个真正适合长期使用的专业动画曲线编辑器。
======================================================================

当前版本存在明显 UI / UX 问题：

1. 曲线图本身尺寸过小；
2. 最重要的 Graph Area 没有成为视觉中心；
3. 顶部大量 Dropdown 平铺；
4. Ease In / Ease Out 等按钮悬浮在大片空白区域；
5. Preview Slider 占据空间过大；
6. Close Graph Editor 按钮过于显眼；
7. 底部 Timeline Search / Filter / Zoom 与上方 Graph Editor 视觉割裂；
8. 信息层级不清晰；
9. 大量空间没有被有效利用；
10. 整体看起来像多个网页控件拼接，而不是专业动画软件。

本次不要单纯：

修改颜色
增加圆角
调整字体

而是重新设计：

Layout
Hierarchy
Interaction
Control Density

参考：

After Effects Graph Editor
Blender Graph Editor
Figma 的 Inspector / Toolbar 信息密度

但不要直接复制视觉资源。

最终目标
======================================================================

打开曲线编辑器时：

用户第一眼应该看到：

“我的动画曲线。”

而不是：

“十几个 Select、按钮和 Slider。”

2. Keyframes / Handles
3. Property Context
4. Precise Parameters
5. Preview Controls

当前版本最大的错误：
