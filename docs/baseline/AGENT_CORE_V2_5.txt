==================================================

Function Calling 是否在当前端点实际可用。

Structured Plan 是否在当前端点实际可用。

必须区分：

LIVE VERIFIED

NOT IMPLEMENTED

NOT VERIFIED。

不允许将离线 Fixture 测试
冒充真实模型验证。

==================================================
六、第一轮真实 Smoke Tests
==================================================

获得授权后，先进行少量真实测试。

TASK A：

创建三个矩形。

分别设置：

红色
绿色
蓝色。

随后将第二个矩形改为紫色。

验收：

对象引用正确。

只有三个新增矩形。

最终颜色正确。

其他对象未被修改。

TASK B：

创建 Cubic 文字。

设置字体、字号、位置、颜色。

验收：

真实 Text Layer 存在。

参数正确。

实际 Renderer 显示文字。

TASK C：

创建径向渐变矩形。

设置渐变中心、半径和色标。

验收：

使用原生 Radial Gradient。

参数合法。

实际渲染出现渐变。

TASK D：

创建矩形。

添加位置关键帧。

使它在两秒内移动。

验收：

Keyframe 正确。

中间帧求值正确。

TASK E：

创建矩形并添加 Gaussian Blur。

如果 V2 尚不支持设置 Blur Radius：

必须明确记录该能力缺口。

不要使用 radius=0 的实例
证明非零模糊视觉效果。

测试全部使用真实 Provider。

不得使用固定响应替代。

七、失败时不要重新开发架构
==================================================

Model

User Request

Parsed Intent

Validation Result

Resolved Objects

Command Execution

Recovery Attempts

Scene State

Render Result

Failure Stage。

针对具体失败定位根因。

如果属于：

则检查模型生成的意图。

如果属于：

Schema Failure

则检查真实参数契约。

如果属于：

Reference Failure

则检查 Runtime 对象引用。

如果属于：

Command Failure

则检查 Editor Adapter。

如果属于：

Renderer Failure

则检查实际渲染。

禁止：

每发现一个错误
就增加一套新管理系统。
