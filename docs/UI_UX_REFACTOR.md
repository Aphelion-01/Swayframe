# UI / UX 重构执行记录

执行基线：docs/baseline/UI_UX_UX1_UX10.txt。按 UX-1 → UX-10 顺序推进，各阶段先通过质量门禁。

Project schema 保持 0.3.0。工具、焦点、面板尺寸、折叠状态属于 UI；所有工程修改继续通过共享 Command System。连续编辑仅预览，释放提交一笔事务，取消恢复。

UX-1：建立中性设计 tokens、共享 IconButton / Section / Tabs / ContextMenu，五区布局与三条可键盘操作分隔线。面板尺寸独立存储，存储失败不阻断编辑，指针取消与 Escape 恢复尺寸。

UX-2：顶部压缩为单行工程菜单、工具、合成标题与预览/导出/历史。画布拖动创建形状和文字，钢笔拖动创建路径；返回选择工具。保留低频创建命令于菜单，回归测试改用真实菜单入口。

UX-3：画布空白框选、Shift 合并、双击内部文字/路径/预合成编辑，Esc 取消当前预览；保留原变换手柄和单次事务。缩放根据画布实际边界补偿鼠标位置，并提供选区缩放、实际尺寸入口。

UX-4：项目/图层 tabs，合成双击打开；图层行可见性、锁定、类型、名称；拖动排序与原地重命名。图层菜单统一构造共享命令，创建父级为一次事务。菜单可使用方向键和 Escape。

UX-5：Inspector 按变换、外观、文字、几何、三维、层级、效果遮罩折叠。动画属性继续统一 AnimatedField，NumericField 提供 scrub 预览与一次提交，方向键精调和 Escape 取消。取消不会修改工程或历史。

UX-6：时间轴拆为精简播放 header、图层/属性列、轨道、底部筛选与缩放；图层默认折叠、选择时展开，变换组可再次折叠。复制/删除/跳转迁入菜单；移除全局自动记录大按钮。提供循环开关与秒/时间码切换。

UX-7：播放头在标尺拖动时实时更新画布；轨道缩放围绕鼠标或播放头并补偿滚动位置。关键帧保持多选拖动，新增框选、Alt 拖动复制、右键插值/复制/删除。持续拖动仍只提交一次命令事务。

UX-8：Timeline / 曲线编辑器 tabs 切换同一底部工作区，Graph 内嵌替代轨道；动画缓动面板保留为独立浮动面板。曲线、速度、空间路径仍读写原数据。

UX-9：全局快捷键从 Toolbar 事件分支迁至统一 Registry；工具/时间轴属性快捷键根据焦点隔离，文字与数值输入保留本地编辑键。Cmd/Ctrl+K 搜索命令，复用已有创建、预合成、模糊、Graph、导出操作。画布、图层、关键帧使用统一右键菜单。

UX-10：统一取消信号接入画布、数字 scrub、关键帧、图层时间、路径、Graph 和 Motion Curve。补充过期 scrub 防护、多关键帧选择保留、钢笔多点一次提交、手机宽度抽屉与键盘可达性。曲线区改为图形/数值两列，保证短时间轴内图形可见。面板调整与场景历史隔离。新增 8 项交互回归测试，保留已有 112 项验证。

产品边界：本轮重构现有编辑器 UI，不新增复杂动画功能或真实 AI 服务。钢笔创建多点折线，双击对象进入已有贝塞尔路径编辑器继续调整切线；不宣称包含完整 Illustrator 钢笔工具。手机窗口侧面板以抽屉访问，复杂时间轴适合桌面窗口。
