# CPU 帧求值基准

同一 Node 运行时，500层、每层100个位置关键帧、120帧；预热一次后5轮中位数。仅衡量核心帧求值，不包括 Canvas、React、素材解码和导出，因此不代表实际预览帧率。

| 场景 | 优化前 ms/帧 | 优化后 ms/帧 | 加速 | 校验值 |
| --- | ---: | ---: | ---: | --- |
| 500 flat animated layers | 2.165 | 0.162 | 13.40倍 | 一致 |
| 500 parented animated layers | 1.853 | 0.222 | 8.36倍 | 一致 |

优化使用父级ID索引，只计算三维层及祖先的world3D，同一帧复用摄像机视图。`npm run benchmark` 可重跑；不同机器/运行轮次会有波动。真实 Canvas 的默认不透明 Source→Output 另使用直接绘制，回归测试验证无离屏分配，半透明/混合效果保持离屏。
