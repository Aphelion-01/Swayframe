## 调试入口

顶部工具：V 选择、H 平移、R 矩形、E 椭圆、P 钢笔、T 文字；钢笔单击多点，Enter 或双击完成，再双击对象进入已有贝塞尔路径编辑。Space 在画布平移，在时间轴播放。Ctrl/Cmd+滚轮以鼠标为中心缩放。

属性面板：拖动数字标签调整，Shift 大步长、Alt 小步长，双击标签精确输入，Esc 取消；秒表开启属性动画，菱形在当前时间记录。画布继续使用原移动、缩放、旋转与锚点手柄。

时间轴：图层展开、变换组折叠；焦点在时间轴时 P/S/R/T 筛选属性；关键帧框选、Shift 多选、拖动、Alt 拖动复制、右键缓动/复制/删除。Timeline / 曲线编辑器切换底部工作区；动画缓动为独立面板。

Cmd/Ctrl+K 搜索命令。左侧项目 tab 双击合成打开，图层双击或 F2 重命名、拖动排序。三条分隔线调节面板尺寸，尺寸独立保存；面板开关可收起面板，画布焦点 Tab 切换侧面板。319px 窗口以抽屉访问侧面板，复杂时间轴仍适合桌面窗口。

## 边界

本轮为 UI/UX 重构，未新增大型动画能力或真实 AI 服务，不宣称已达到 AE 全部功能。钢笔创建多点折线，贝塞尔切线继续在已有路径编辑器编辑。未新增完整 Illustrator 钢笔曲线创建。原有 Effects / Mask / 3D / Agent / 导出算法未重写。

本轮实测集中于编辑交互；PNG 序列的逐帧像素一致性属于先前版本验收，不作为本轮新增 GUI 实测结果。Scene 修改保持共享 Command System；复杂批量操作由 Transaction 提交；Intelligence 只生成 Proposal。
