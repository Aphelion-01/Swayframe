# 基础编辑更新

2026-10-03，按用户确认的范围完成。该更新扩充常用编辑操作，不代表完整 AE 功能集。

## 已完成

- 经典实心菱形：当前时间关键帧用黄色，选中用亮蓝色；增大点击区域。
- 默认自动位置关键帧：拖动、方向键微调和对齐操作在当前位置记录；第一次在后续时间移动时，保留 0 秒起点并添加当前帧。连续拖动只有松手提交一笔历史。同一时间重复移动更新原帧。
- 四属性秒表：位置、缩放、旋转、透明度开启后，Inspector 修改自动记录当前帧；关闭会移除该属性动画、保留当前显示值，可撤销。
- 关键帧拖动、按帧吸附、Shift 多选、复制粘贴、批量删除、上/下关键帧跳转。复制保留相对时间间隔及插值；单图层复制可粘贴到其他选中图层；目标时间已有帧时覆盖，整体可撤销。拖动冲突或越界明确拒绝，不修改工程。
- 图层 Shift/Cmd/Ctrl 多选、批量移动、复制、删除；复制图层重新生成 ID，保留动画，图片素材可一同复制到新工程。
- 左/右/顶/底对齐、水平/垂直居中；三个以上图层可按中心等间距分布。边界对齐考虑缩放与旋转，锁定图层不参与移动。
- 画布 50%～400% 缩放、Ctrl/Cmd+滚轮连续缩放、中键或 Alt+拖动平移。
- 时间轴 1×/2×/4×/8× 缩放及横向滚动；属性筛选全部、已有动画或单属性。窄窗口保持有效轨道宽度。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 撤销 / 重做 | Cmd/Ctrl+Z / Shift+Cmd/Ctrl+Z |
| 保存 | Cmd/Ctrl+S |
| 全选图层 | Cmd/Ctrl+A |
| 复制 / 粘贴选中图层或关键帧 | Cmd/Ctrl+C / V |
| 复制图层 | Cmd/Ctrl+D |
| 删除选中关键帧；没有选中关键帧时删除图层 | Delete / Backspace |
| 播放 / 暂停 | Space |
| 图层微调 | 方向键；Shift 为 10 像素 |
| 播放头逐帧移动 | Cmd/Ctrl+左/右；Shift 为 10 帧 |
| 筛选位置 / 缩放 / 旋转 / 透明度 / 已有动画 | P / S / R / T / U |
| 清空选择、取消画布拖动 | Escape |

编辑文字或数值时，快捷键不会误删图层或触发工程级操作。保存快捷键仍可使用。

## 检查

17 个测试文件、68 项测试通过；typecheck、lint、build 通过。新增测试覆盖首次自动关键帧、重复更新、动画关闭保留值、多图层事务、锁定保护、ID 重建、时间冲突、复制间隔、图片素材、对齐边界、键盘焦点隔离。

实际浏览器检查：菱形从 1 秒拖到 1.5 秒并撤销；0/1 秒多帧复制到 2/3 秒并撤销；新矩形在 1.5 秒首次拖动生成 0 和 1.5 秒关键帧；图层复制、多选对齐、4× 时间轴缩放；400% 画布 Alt 拖动产生 100/60 像素滚动，浏览器无运行错误。

所有工程修改仍经共享 Command/Transaction；拖动预览、选择、剪贴板和缩放属于 UI 状态，不写入 Scene。保持原 JSON 版本与格式，旧工程兼容。未增加 3D、复杂特效、视频导出或真实 AI 模型等范围外功能。
