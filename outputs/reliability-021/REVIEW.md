# 0.9.21 修复记录与验收边界

1. 3D 地面网格跟随视图目标和缩放展开，线段按距离渐隐；删除摄像机“拍摄中/未生效”后缀，保留图层名称。并非增加物理场景尺寸限制。
2. Agent 修复纯文字无计划、非法节点参数、越界计划和新建图层视觉修正的校验基线；错误计划不能写工程。持续数据流使用空闲超时而非固定总时长中断。真实 Provider 检查结果另见 live-report.json，不用单元测试替代在线验证。
3. 父级图标统一；拖线落在整个目标图层行即可绑定。真实共享 parentCommands 的落点、撤销、取消测试通过，循环绑定由核心拒绝。
4. 绿色条来自真实缓存，默认256 MiB，删除固定16帧上限，同一时间不同尺寸不重复计数；修改工程、淘汰或清空缓存后取消标记。
5. 创建菜单移除径向渐变，加入三维模型导入；径向渐变算法继续属于合成效果能力。
6. 导入入口支持图片、音频、视频。识别 PNG/JPEG/WebP/GIF/BMP/AVIF，MP3/WAV/FLAC/OGG/Opus/M4A/AAC，MP4/MOV/WebM/MKV/TS/M2TS。容器识别不保证每一种内嵌编码：实际解码能力按设备检测；测试已验证合成 PCM WAV 的真实解码、工程保存重开及撤销。其余格式未逐一进行真实文件验收。桌面256 MB，Web10 MB。导出包含混合音轨，不保证所有设备的编码器。
7. 模型新增线框、材质乘色、无光照原色、背面剔除，并保留XYZ位置/旋转/缩放/锚点；不具备 Blender/C4D 完整建模、材质节点、纹理或骨骼编辑能力。
8. 图层行加入动态图标开关；五次时间采样平均透明颜色，预览和导出共用 Renderer。视频内容本身的帧间光流不在此实现范围。
9. 时间刻度裁剪至轨道边界，避免与右侧插值栏重叠。
10. 线性和贝塞尔速度改用解析导数，空间路径也使用解析切线；大坐标摄像机稳定性回归通过。

## Feature Placement Review / UX 检查

Scene: 创建/导入复用已有菜单；父级拖线和动态模糊属于图层上下文。Inspector: 模型参数在现有 ThreeDControls Section。Motion: 缓存指示沿用时间轴状态区域。Intelligence: 没有新建全局按钮。没有修改全局工具栏预算。Feature 元数据与位置清单已重新生成；具体参数通过注册 Section 使用 Command，而非独立无参全局入口。

可发现性：父级图标和动态模糊提供操作说明，拖线显示连接反馈。错误预防：解码失败不插入素材；父级循环核心校验；Agent 在预览之前验证语义和范围。取消/撤销：拖线取消无历史，正式编辑走共享事务。状态可信度：绿色只标真实保留缓存。

自动界面操作接口在本轮仍发生超时；未完成新的截图与端到端界面验收。不得把代码/单元测试 PASS 说成所有模型、媒介格式和渲染视觉均已实测。
