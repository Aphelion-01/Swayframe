# Motion Editor V0.2 验收与调试

Phase A～I 已完成。91 项自动测试及全部质量门禁通过；CASE01～11 已通过真实界面操作，测试通过和功能验收分别记录。

## 开始调试

开发预览：<http://127.0.0.1:5174/>。点击“打开工程”，选择 [综合验收工程](examples/MotionEditor_CASE01_11.motion.json)。它包含两合成、十一图层、复用图片、动画遮罩、效果、父级、预合成、三个三维平面和动画摄像机。在 0～1 秒播放查看入场、过冲与摄像机推进；进入“预合成 1”可编辑矩形与圆的曲线。

默认拖动画布图层生成位置关键帧；其他属性开启秒表后会在当前时间记录修改。曲线编辑器可拖入/出切线，也可输入影响比例和速度。复杂编辑提交一笔可撤销 Transaction。

## 当前边界

GIF 静态显示；视频解码、MP4 导出未提供。三维为平面透视，不含实体建模、灯光或逐像素深度缓冲。路径点数不同采用保持插值；带剪切的父级重定向受 TRS 表达能力限制。复杂效果依赖本机 Canvas 性能；序列导出单次最多 3000 帧或 512 MB。智能辅助仍为演示服务。
